
# Badges

방송 화면 하단(로어서드)과 **수어 아바타 신원 표시**에 쓰는 미디어 배지입니다.
Identity badges for broadcast lower thirds and sign-language avatar name chips.

실사 푸티지는 프레임마다 밝기가 바뀌므로 정적인 대비 계산이 성립하지 않습니다.
그래서 모든 배지에는 **스크림 플레이트**가 미리 적용되어 있습니다.

| 스타일 | 스크림 | 마크 | 사용 |
| --- | --- | --- | --- |
| `dark` | `#0B1218` @ 72% | 풀컬러 | 밝거나 대비가 심한 푸티지 |
| `light` | `#FFFFFF` @ 86% | 포지티브 스페이스(단색) | 어둡고 균일한 푸티지 |

## 파일 / Files

| 파일 | 크기 | 용도 |
| --- | --- | --- |
| `badge_avatar_dark_{128,256,512}` | 원형 | 수어 아바타 신원 칩, 참가자 타일, 프로필 표시 |
| `badge_avatar_light_{128,256,512}` | 원형 | 위와 동일, 밝은 스크림 |
| `badge_lower_third_dark_960x160` | 알약형 | 1080p 타임라인용 로어서드 |
| `badge_lower_third_dark_1440x240` | 알약형 | 4K 타임라인용 로어서드 |
| `badge_lower_third_light_960x160` | 알약형 | 1080p, 밝은 스크림 |
| `badge_lower_third_light_1440x240` | 알약형 | 4K, 밝은 스크림 |

각 파일은 `.png` 와 무손실 `.webp` 로 제공됩니다.

## 텍스트 영역 / Text area

로어서드 플레이트에는 **글자가 들어 있지 않습니다.** 이름·직책은 편집 도구에서 직접 올리며,
아래 영역 안에 배치하고 세로 중앙 정렬합니다.

| 플레이트 | 마크 | 텍스트 영역 (x 범위) | 텍스트 폭 |
| --- | --- | --- | --- |
| `960×160` | 지름 115 px, x=22 | 166 – 915 px | 749 px |
| `1440×240` | 지름 173 px, x=34 | 250 – 1373 px | 1123 px |

- 텍스트 대비는 스크림 대비 **4.5:1 이상**을 확보합니다.
- 텍스트가 영역을 넘치면 글자를 줄이지 말고 **플레이트를 넓혀** 다시 생성합니다
  (`generate.py` 의 `LOWER_THIRD_SIZES`).
- 브랜드 전용 서체는 지정되어 있지 않습니다. 팀 표준 서체를 쓰되, 새 서체를 자산으로
  추가하려면 스태프 승인과 폰트 라이선스 확인이 필요합니다.

## 배치 / Placement

- 액션 세이프 영역(프레임의 93%) 안, 하단 가장자리로부터 프레임 높이의 **8%** 위.
- 아바타 칩은 **최소 128 px** 이상으로 표시합니다.
- 수어 통역 화면에서는 **통역자의 손 동작 영역을 가리지 않는 위치**를 우선합니다.
  겹치면 로어서드를 반대쪽으로 옮기고, 그래도 겹치면 `badge_avatar_*` 로 대체합니다.

자세한 규정은 [`../MEDIA_GUIDELINES.md`](../MEDIA_GUIDELINES.md) §3.4 · §4.3 참조.
